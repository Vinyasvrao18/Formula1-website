# 🏎️ Formula 1 Interactive 3D Website

A modern and interactive **Formula 1 website** designed to provide users with an immersive experience of the world of F1. The website combines **Formula 1 information, responsive web design, interactive UI components, and a real-time 3D Formula 1 car model** to create an engaging experience for motorsport enthusiasts.

### 🚀 Key Features

* 🏁 **Interactive Home Page** – F1-inspired interface with a modern racing-themed design.
* 🏎️ **3D Formula 1 Car Model** – Interactive 3D car that users can rotate, zoom, and explore directly on the website.
* 🏆 **Teams Section** – Displays information about Formula 1 teams and their drivers.
* 👨‍✈️ **Drivers Section** – Provides driver profiles and relevant information.
* 🗓️ **Race Calendar** – Displays Formula 1 races and circuit information.
* 📰 **F1 News Section** – Dedicated section for Formula 1-related news and updates.
* 🛣️ **Circuit Information** – Showcases different F1 tracks and their details.
* 📱 **Responsive Design** – Designed to work across desktops, laptops, tablets, and mobile devices.
* 🎨 **Modern F1-Themed UI** – Uses racing-inspired layouts, typography, animations, and visual elements.

### 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, animations, and responsive layouts
* **JavaScript** – Interactivity and dynamic content
* **Three.js** – 3D graphics and interactive Formula 1 car model
* **GLB/GLTF** – 3D model integration

### 🎯 Project Objective

The main objective of this project is to combine **web development and 3D graphics** to build an interactive Formula 1 experience. Instead of presenting information through a traditional static website, the project uses **Three.js and a 3D F1 car model** to make the website more visually engaging and interactive.
